# M4 — First persistent AI tutor flow

Status: implemented and verified; homework parsing remains synthetic.

## Included

- Authenticated `POST /api/sessions` creates an owner-scoped Supabase session.
- Authenticated `POST /api/tutor` validates a provider-neutral request contract.
- Student and tutor messages are persisted through the caller's Supabase access token and RLS.
- Client message IDs make retries idempotent.
- Vercel AI Gateway is the default provider boundary; the model is selected by
  `MATTIS_TUTOR_MODEL` and defaults to `openai/gpt-5.6-luna`.
- Gateway requests enforce zero data retention when `MATTIS_AI_ZDR=true`. The closed Hobby PoC keeps
  it disabled and permits synthetic, non-identifying test data only. Provider failure degrades to a short, pedagogical
  local hint without logging pupil text.
- AI generation records contain metadata only. Conversation content follows the shorter message
  retention policy.
- Sessions now have an explicit 180-day deletion deadline and append-only tutor evidence.
- A preview/development-only synthetic route at `/__test/session` supports visual agent testing
  without authentication, database calls or user data.

## Verification

- TypeScript, ESLint and Next.js production build pass.
- 35 unit tests pass across auth, schema, persistence, preview isolation and tutor behavior.
- Supabase security advisor reports no table/RLS findings after the retention migration.
- The remaining password-protection advisor warning does not affect the OTP-only pilot.

## Not complete yet

- Homework image upload, OCR/parser and task confirmation are still visual mocks.
- Existing message history is stored but not hydrated back into the chat after reload.
- Learning evidence is supported by the data layer but is not yet written from every tutor turn.
- Scheduled sessions, automatic retention cleanup, export/deletion UI and guardian/consent flows
  remain required before a real-pupil pilot.
- Curriculum content and source versioning must be populated before curriculum-grounded answers can
  be claimed.
