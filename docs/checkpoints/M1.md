# M1 — Interactive product prototype

Status: implemented; engineering gates passed; visual comparison completed; browser interaction
verification is blocked by the cloud preview client not hydrating client-side handlers.

## Included

- Mobile-first Next.js app for the complete synthetic Nora journey.
- Onboarding, home plan, session setup, homework capture, task review, tutor chat, geometry task,
  summary, and privacy routes.
- Planned-session rail and timer retained inside the chat-led tutoring experience.
- Official Lucide icon assets stored locally under the ISC license.
- Deterministic algebra and geometry content; no AI-generated production illustrations.
- Internal `mobile-preview.html` helper for repeatable 426 × 923 visual QA.
- Browser-rendered home, algebra, and geometry comparisons under `design-qa/images/`.

## Deliberately excluded

- Supabase project, authentication, persistence, or storage.
- OCR, camera upload processing, AI model calls, or generated task illustrations.
- Real student data or production analytics.
- Public deployment.

## Quality status

- Formatting, TypeScript, ESLint, unit tests, and production build: passed on 2026-08-22.
- Visual QA: source and implementation compared at the same mobile viewport.
- Browser console: no app-origin errors observed; the cloud-browser extension reports unrelated
  metadata errors.
- Main interaction test: blocked in this preview client because Next.js client handlers do not
  hydrate; native link navigation works. The Playwright journey remains committed for execution in
  a normal browser runtime.
